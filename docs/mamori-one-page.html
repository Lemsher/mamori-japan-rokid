核心产品流程

  1. 1
    确认所在地

    GPS、语音 / 地址、列表或邮编；由用户确认市町村，沿海另确认海啸预报区。

  2. 2
    读取官方信息

    JMA 天气与灾害电文；新鲜严重匹配记录可在前台自动打开详情。

  3. 3
    一屏查看行动

    按情境进入双语指南；包含道路受阻、无法安全外出的补充分支。

  4. 4
    查地点，接导航

    GSI 地点按灾种筛选；网页地图链接，原生 Hi Rokid 目的地交接。

紧急情境可直达：明确的危险描述可跳过定位与联网，打开本地指南。

7 类情境指南地震 · 海啸 · 滑坡泥石流 · 暴雨 / 洪水 / 风暴潮 · 台风 / 暴风 · 火山 · 日常准备

已实现 / 有验证记录

原生 AIUI + 网页联调端：选址、双语指南、灾害信息展示、避难地查询及导航交接。项目记录 58 项自动测试通过，并有离线指南与 390px 显示验证。

下一阶段 / 尚未验收

生产 HTTPS 服务、Studio 重导入与眼镜真机验收；真实日语语音、后台通知送达、秒级地震预警和眼镜自动导航接入。

当前定位：防灾辅助开发原型，不能替代官方紧急播报。无记录不等于安全；避难地点开放与道路安全未确认。紧急时优先保护自己，遵循地方政府、气象厅及现场指示。
