# v0.2.1 Ink UI 与返回导航验证

日期：2026-09-11。本轮直接在官方 Ink 0.17.0 画布内渲染实际 `.ink` 页面，通过鼠标、物理键盘及预览镜腿按钮操作。未用网页联调端的 HTML 组件代替原生验收，也未重新导入 Studio 或连接眼镜真机。

## 本轮修改

- 首页、选址、指南、预警、避难地五页统一为左右卡片：左侧所在地/首要行动/筛选，右侧行动/要点/结果；使用单色图标加文字、明确的选中箭头、固定返回入口。
- 保持 480×352 原生画布和单色绿色显示；指南仍是首要行动与三条要点同屏，未改变安全内容。
- Backspace 与页面返回按钮一步返回；预览支持 Esc。保留原生页面栈，单页直达无上级时回首页。首页返回只提示已在首页。
- 地区列表进入市町村后，返回恢复之前的地区页及页码。确认地区或沿岸后回到原调用页，避免重复压入首页。

- 本地预览继续由官方 CLI 生成，新增中文镜腿说明、物理键盘分发和小屏等比例画布。网页联调端增加原生演示入口。

## 修复的实际兼容故障

- 原生`tap`事件读取`currentTarget.dataset.code`抛TypeError；实际事件提供`currentTarget.attributes['data-code']`。地区和避难地列表统一修复。
- Ink 0.17浏览器构建中，省略headers时出现“Headers constructor requires …”。共享取数与GSI地址转换显式提供`headers:{}`。
- 同一构建实测`new Date().toISOString()`生成异常日期字符串，导致已有预报仍显示未确认。原生抓取时刻改用Date.now，JST以整数时间格式化；不改变源电文时间。
- 默认焦点状态在不同宿主里不够明确，使用文档支持的Page onKeyUp维护可见箭头，Enter先选择再激活，上下循环、返回清除或退回；滚动容器跟随所选控件。
- 原生speechSynthesis.cancel在0.17未暴露，退出指南曾抛错。改用文档支持的synthesize与独立SpeechAudioPlayer，页面退出释放播放器和任务。真实声音未实测。
- CLI预览固定运行时版本、scaleFactor=1（与Studio常规预览一致），开启渲染循环和宿主交互；支持指定页面/参数。构建同步更新离线缓存内容摘要，避免新页面搭配旧离线模块。

截图以`v2-`开头；其余旧截图属于早期版本，不能用来验收0.2.0。官方初始模板对循环项动态属性可能输出缺失变量的警告，实际点击取得的属性和跳转已验证；核心流程退出时不应再有异常。
