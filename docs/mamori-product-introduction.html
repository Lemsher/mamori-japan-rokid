DESIGNED AROUND THE MOMENT

关键时刻，少一点查找。

产品首先关注所在地、信息理解和即时行动之间的断点。以下是目标使用场景，尚无用户效果数据。

在日居民 · 所在地

这条信息，与我有关吗？

确认市町村后匹配区域通报，保留来源与时间；海边使用时另行确认海啸预报沿岸。

赴日旅行者 · 理解

提供日中双语行动内容，把首要行动与三条要点放在同一屏，降低翻找和阅读负担。

Rokid 佩戴者 · 行动

从“知道”接到“下一步”。

FROM INFORMATION TO ACTION

一条连贯的防灾辅助流程。

常规流程先确认地点。遇到明确危险情境，可直接进入本地指南。

确认我在哪里

GPS、语音 / 地址、地区列表或日本邮编，展示候选后由用户确认市町村。

GPS 与语音入口仍待真机验收

了解当地信息

读取 JMA 天气和灾害电文。新鲜、严重且地域匹配的新记录，可在前台自动打开详情。

前台 60 秒刷新；不是秒级地震预警

一屏查看行动

按情境呈现首要行动和三条要点。遇到道路积水、无法外出时，切换相应分支。

原生安装包内置；网页须提前缓存

查找避难地点

查询 GSI 指定紧急避难场所并按灾种筛选；网页打开地图，原生提供导航交接信息。

地点开放与道路通行需另行确认
紧急情境直达

描述“海边感到强烈摇晃”等明确情境，可跳过定位与联网，打开对应离线指南。先保护自己，避免因查看屏幕而延误行动。

TRUST IS IN THE DETAILS

每一步，都保留依据。

防灾场景需要可追溯的信息，以及清楚表达“尚未确认”的能力。

SOURCE / 来源

官方信息，保留原意。

使用日本气象厅（JMA）天气与灾害电文、国土地理院（GSI）地点数据。震度、震级、气象警报与火山等级分别表达。

UNCERTAINTY / 未知

没有记录，不等于安全。

断网、过期和无匹配记录都不能解释为安全或警报解除。公开通报不代表完整的当前有效警报状态。

AGENT / 角色

识别情境，连接行动。

明确描述优先本地匹配；可用模型仅辅助分类。灾害事实与行动文本不由模型自由生成，也不凭模型判断路线安全。
