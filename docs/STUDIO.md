# Studio 上传与预览 · v0.2.2

本次新版在本地官方 Ink 0.17.0 中完成交互验证，未重新导入用户当前 Studio 草稿。旧草稿不会自动更新。

## 上传新版

1. 解压 `dist/mamori-japan-0.2.2-studio.zip`，得到 `agent` 文件夹；也可直接用项目内的 `agent`。
2. 打开 [AIUI Studio](https://aiui.rokid.com/)，选择“新建智能体 → 本地导入”，选择上述 **agent目录**。目录第一层应有 `AGENTS.md`、`app.json`、`app.js`、`pages`、`modules`。系统目录访问授权由用户处理。
3. 检查 `pages` 下有 home、location、alert、guide、shelters 五个页面，`modules` 有 postal-data.js 和 keys.js。
4. 进入“真机模拟”，在效果预览旁点击“直接运行智能体”或“重新运行智能体”。核对首页 **v0.2.2**。

当前 Studio 本地导入使用源目录；`.aix` 是官方构建/安装产物，不要把整个项目、ZIP文件或`.aix`当源目录导入。预览不需要提审发布。

## 交互验证顺序

Studio绿色Canvas刻意设置了 `pointer-events:none`，不能像普通网页一样直接点击或键入。使用右侧“镜腿操作”和“语音输入”。

1. 镜腿前后滑动对应上下选择。箭头 `▶` 标示选中项；单击确认。首次确认键先选中第一项，再确认执行。返回键一步返回上级；市町村返回原地区列表及页码，再返回才离开选址页。直接打开的指南等页面没有上级时回首页。
2. 地址/邮编输入：点击右侧麦克风唤醒页面ASR，在右侧输入框键入 `150-0001`、`東京都渋谷区神宮前1丁目` 或 `Tokyo Shibuya` 并发送。输入框如显示“等待页面开启ASR”，先唤醒，再发送。Studio文字是模拟识别结果，不要求真实说话。
3. 确认候选“東京都 渋谷区”，首页显示所选地区。也可通过地区列表逐级选择。邮编可能有多个候选，需自行确认。
4. 打开海啸/地震等指南，确认首要行动和3条要点同时显示，页面没有“下一步”。选择“附近避难地”进入灾种筛选和GPS查询。
5. 如在海边，通过预警页“确认海啸预报沿岸”选择正确沿岸。市町村和海啸预报区并非一一对应。

本地原生预览的右侧 Enter、↑、↓、返回与镜腿按键使用同一套页面事件；本地Canvas还可点击，但这项鼠标能力不代表StudioCanvas支持鼠标。

## GPS、天气及导航

GPS真实能力及权限由宿主提供。点击后若失败会提示改用地址、邮编或列表；当前包没有内置模拟GPS。实际Glasses定位、手机连接、权限和日本语音识别尚未验证。不要在浏览器拒绝权限后把候选测试当作真实GPS成功。

本包预警后端 `SERVICE_URL` 为空。网络可用时原生直接获取JMA预报，并明确标记预警服务未接通；网页联调端则调用本地后端，包含天气、气象预警和本地匹配的地震/海啸/火山电文。要让Studio/眼镜取得聚合数据，需部署HTTPS后端，填写该配置并重新导入。

网页导航链接打开步行地图；原生暂时显示目的地名称、地址和Hi Rokid指令。并未接通眼镜导航自动启动接口，也不保证地图路线适合当下灾害。公开XML分钟级信息不提供秒级地震预警。

本次修复了原生点击事件错误读取dataset、未显式提供请求头、浏览器Ink日期格式异常，以及页面退出时调用未支持的speechSynthesis.cancel等问题。实际修复和验证见 [VALIDATION.md](VALIDATION.md)。

本地演示推荐直接打开 [官方 Ink 画布](http://127.0.0.1:8787/aiui-runtime.html?lang=zh)。键盘 ↑/↓、Enter、Backspace/Esc 与右侧按钮走同一原生输入分发路径。

0.2.2 首页应对区仅图标+标题，点击后进入完整指南。地区表按2024年10月都府县人口排序，地方分区末置；温度标为代表地点日间最高预报，降水概率标明6小时时段，未知值不填0。
