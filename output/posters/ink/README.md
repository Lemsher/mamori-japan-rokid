三张 3840 × 2160 PNG，16:9 横向；正式交付不使用 AI 生成图。打开 index.html 可浏览全部海报。

- ikeda.png：大阪府池田市，日常与地震模拟。
- wakayama.png：和歌山县，日常与虚构火山喷发演练。
- iwate.png：岩手县沿岸，以宫古市为所在地，日常与地震后海啸警报演练。

## 新增：首页灾害提示中间状态

三张海报均升级为四屏：日常首页 → 灾害首页 → 灾害详情 → 行动指南。screens/*-warning.png 是新增的首页原生 Ink 截图。

新增 runtime/*-warning.html 为独立暂停展示副本：数据适配器在内存中将模拟记录的 status 映射为通常，并填入构建时 ISO 发布时间，以通过原生 mayInterrupt 条件，驱动未经修改的 homeWeather 与首页 .ink 进行真实渲染。这些值仅供测试，并非真实官方电文；界面外始终标注模拟情境。生产源码、状态判定函数、首页模板与样式均未改变。为停留在自动跳转前的首页瞬间，演示适配器仅调用 onSnapshot，不调用 onAlert；这不是实际产品会停留等待的承诺。

警报事件时间超过十分钟后不再满足原生新鲜度条件，因此复现中间状态时须先重新执行构建脚本，再立即截图。日常、详情、指南副本仍使用原有演练数据。

新增中间状态的画面已逐张核对：池田市显示地震情報，和歌山市显示噴火警報，宫古市显示津波警報 / 地震情報；天气数值隐藏、标题增加 !、底部提示已取得预警记录。最终三个 PNG 均为 3840 × 2160，四张图片全部加载，未发现页面出界及页脚重叠。

## 截图来源

screens/ 中的十二张图片直接截取官方 Ink 0.17.0 的浏览器 canvas。页面来自当前 agent/pages/home/index.ink、alert/index.ink、guide/index.ink；没有重画产品界面，没有修改这些页面的布局、文字模板、字体或控件。运行时使用 scaleFactor=3 提高原生画布精度。

runtime/ 是独立展示副本，与产品源代码隔离。仅将副本的 monitoring.js 换成明确的演练数据适配器；为避免假冒官方数据，副本 alerts.js 对 status=訓練 的记录显示“模拟演练 · 非官方发布”。所有 .ink 文件与项目源文件逐字一致，SHA256 记录位于 runtime/*-ink-sha256.json。没有接入真实推送、没有对外发送灾害通知。

日常副本的灾害记录为空；气温、降水、震度、震级、预计海啸高度、火山等级均是演练设定。展示时间来自渲染时钟，不是官方发布时间。地震页是震后信息；海啸演练未设置到达时刻，不展示倒计时。

岩手副本包含海啸与地震两条记录，首屏展示海啸，可通过“其他预警”切换查看地震。所选海啸预报区为岩手県，市町村为宫古市。

## 复现与检查

在项目根目录执行 scripts/build-ink-posters.py 生成独立运行时，scripts/layout-ink-posters.py 生成 HTML 版式。用本地 HTTP 服务提供本目录，在 Ego Browser 中运行 capture-screens.mjs 和 export-posters.mjs。脚本中的 taskSpace(8) 为本次浏览器空间 ID，复用时需替换成新建空间 ID。重新加载 Ink SDK 需要联网。

已检查：三张 PNG 均为 3840 × 2160；三张版式图片全部加载，横向和纵向均无出界元素；底部价值文案与页脚不重叠；逐张查看最终渲染；全部原生 .ink 文件哈希与源码一致。layout-qa.json 保存浏览器检查记录。
