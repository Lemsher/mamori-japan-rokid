# MAMORI 精简宣传海报

四张 3840 × 2160 PNG（16:9）：overview 产品总览；ikeda 池田市地震；wakayama 和歌山虚构火山演练；iwate 岩手沿岸地震与海啸。

打开 index.html 浏览全部；同名 HTML 为可修改版式。

本版沿用已经验证的真实 Ink 画布截图，不使用图像生成，不重画产品页面。screens/ 文件与 ../ink/screens/ 原图逐字一致，SHA256 保存于 screenshot-sha256.json。截图中的日期与指标均属于原演练设定，不是实时信息。原生产品源码没有修改。

灾害海报均保留四屏：日常首页 → 灾害首页中间状态 → 灾害详情 → 行动指南。中间状态通过独立演示副本暂停自动跳转后截取。原生首页布局与灾害判断逻辑未修改；模拟数据和捕获机制详见原包 ../ink/README.md 及其 runtime/。

精简策略：短主标题、四屏状态标签、三个亮点，保留必要的模拟标记和能力边界。三张灾害海报截图外的可见文字分别从 614 / 630 / 638 字符减至 296 / 324 / 323 字符（包含字母与标点、排除空白、排除截图内文字），约减少一半。产品总览集中呈现所在地确认、天气与灾害信息、中日双语离线指南及按灾种查询避难地点。

和歌山及周边无活火山，本海报为虚构演练，非当地风险评估；资料来源延续原海报核验记录：
https://www.data.jma.go.jp/wakayama/bousai/paper/wakayama_jishin/2406.pdf

生成版式：在项目根目录运行 python3 scripts/build-concise-posters.py。以 HTTP 服务提供本目录，在 Ego Browser 内执行 export.mjs；taskSpace(9) 是本次空间 ID，复现时需替换成新空间 ID。版式生成与 PNG 导出均不需要调用图像生成功能。

验证：四张 PNG 尺寸 3840 × 2160；截图源文件哈希一致；页面图片全部加载；无出界元素、图注溢出或页脚重叠；四张最终成品均已逐张目视检查。qa.json 为浏览器检查记录。
