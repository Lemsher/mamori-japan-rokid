# まもり / MAMORI · Rokid Glasses 日本防灾智能体

版本 **0.2.2**，2026-09-11。提供原生 AIUI 智能体及本地网页联调端。已构建和验证主要交互；尚未重新导入 Studio、部署生产服务或连接 Rokid Glasses 真机。

地区入口按2024年10月都府县人口降序，名称以“地方”结尾的13个分区统一放到最后。首页应对卡片只展示图标与标题，点击进入完整指南子页面。未取得预警记录时，天气卡片显示当日预报图标、代表地点的日间最高气温及当前/下一个6小时降水概率；缺失显示“—”，预警未确认单独标注。

五个原生 Ink 页面统一为左右卡片布局，配单色说明图标：左侧是所在地、首要行动或筛选，右侧是行动卡片、指南要点或结果。返回键一次返回上级；市町村列表返回原地区页，单独打开的页面回首页。

首页支持 GPS、语音/地址、地区列表和日本邮编。确认市町村后显示天气及可取得的灾害信息；新的匹配严重通报可自动打开详情。七类自救指南均为“一屏行动 + 三条要点”，不再手动翻页。指南可进入按灾种筛选的指定紧急避难场所，海啸地点补充地面海拔；网页可打开步行导航，原生端提供 Hi Rokid 导航交接信息。

## 运行与导入

```sh
python3 -m server.app
```

Python 3.11+、curl；默认仅监听 `127.0.0.1:8787`，无需 Python 第三方依赖。

- [网页联调端](http://127.0.0.1:8787/)：本地后端接入真实公开 JMA/GSI 数据。
- **推荐演示：[原生 Ink 首页](http://127.0.0.1:8787/aiui-runtime.html?lang=zh)**：实际 `.ink` 页面在官方 Ink 中运行。
- [邮编候选示例](http://127.0.0.1:8787/aiui-runtime.html?page=location&query=150-0001&lang=zh)：示例是涩谷区，不是用户 GPS。
- [原生一屏海啸指南](http://127.0.0.1:8787/aiui-runtime.html?page=guide&hazard=tsunami&lang=zh)。

Studio 选择“新建智能体 → 本地导入”，选本项目的 `agent/` 文件夹。也可解压 `dist/mamori-japan-0.2.2-studio.zip` 后选择其中的 `agent/`。网页导入源目录，不是 `.aix`。运行后核对首页 **v0.2.2**；完整操作见 [STUDIO.md](docs/STUDIO.md)。

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm run pack
python3 scripts/release.py
```

官方 CLI 0.8.2 / Ink 0.17.0，产物为 `dist/mamori-japan-0.2.2.aix`、Studio 源码 ZIP、完整源码 ZIP 和 SHA256。`pnpm run pack` 与 npm 打包命令 `pnpm pack` 不同。

## 本版能力及边界

| 功能 | 已实现 | 仍需接通或实测 |
| --- | --- | --- |
| 所在地 | 离线地址、地区列表、120,717 个邮编；定位候选确认；不会默认东京 | 真实 GPS 权限、Rokid 手机连接和日本语音识别 |
| 天气 | 原生JMA当日预报：天气图标、代表地点日间最高气温、分时降水概率、来源及发布时间 | 是预报而非实时气温/实测降雨量；未取得的指标显示“—” |
| 气象/土砂 | 精确市町村正文匹配；2026 VPWW55–61，兼容 VPWW53 | 公开 feed 并非全部当前有效警报；地方政府避难指示未接入 |
| 地震 | VXSE53 实测震度、震级、震源；震度≥3且新鲜的匹配记录可触发前台提示 | 震后信息，不是秒级 EEW；不能显示自算的地震倒计时 |
| 海啸 | VTSE41 对应手动确认的沿岸；预计高度和明确到达时间 | 市町村不能自动等同沿岸；解析以模拟电文测试，未遇到实时海啸公告 |
| 火山 | VFVO50 对应市町村及火山的明确警戒信息 | 喷发速報、完整持续状态追踪未接入；不预测喷发时间 |
| 预警跳转 | 前台60秒刷新，新鲜/严重/地域匹配、去重后自动打开详情 | App关闭或后台持续送达未完成；已有服务器通知模块仅支持气象警报 dry-run |
| 自救 | 7类日中双语，首要行动及三条要点一屏显示；室外危险替代分支 | 中文为编辑摘要；仍需眼镜佩戴阅读与真实场景验收 |
| 避难地 | GSI指定紧急避难场所按灾种过滤；10km内最多8处、直线距离；海啸前3处尝试查地面海拔 | 开放情况、道路通行、高地路径安全不能由这些资料保证 |
| 导航 | 网页打开Google Maps步行路线；原生显示目的地和Hi Rokid指令 | AIUI公开接口中未接通自动启动眼镜导航；不能称已开始导航 |
| 朗读 | 原生使用独立SpeechAudioPlayer，页面离开时释放；网页选择可用音色 | 日语原生TTS默认关闭，真实播报和语音精度未验收 |

原生 `agent/modules/config.js` 的 `SERVICE_URL` 仍为空。其可直接读取 JMA 天气；预警和灾害聚合需部署本后端到 HTTPS，再配置并重新导入。浏览器首次加载 Ink SDK 需要联网；离线网页需先完整在线打开并安装 Service Worker。原生安装包包含指南和地区表，不依赖浏览器 Service Worker。

气象警报等级、地方政府避难指示、震度、震级和火山警戒等级分别保留，不混为同一“强度”。只有官方海啸电文明确给出对应沿岸最早到达时刻时才显示倒计时，并提示不要等待。查询快照超过120秒显示未确认；无记录、过期、断网都不表示安全或解除。当前公开信息产品不能替代官方紧急预警。

## 可选后台检查

```sh
python3 -m server.monitor --city 1311300 --once
```

默认 dry-run，以上是示例市町村。没有安装定时任务或开机服务，没有发送真实通知。实际接收人须订阅，并在服务器配置 `.env.example` 中的三个 ROKID 环境变量（程序不会自动加载 `.env`）。只有正常发布/订正、明确等级≥3、10分钟内且来源已确认的气象预警可构造通知；已有成功回执会持久去重。地震/海啸/火山后台投递、多用户订阅/撤销、解除闭环、可靠性和真机回执仍待实现。勿把开发HTTP端口直接当生产服务。

## 数据与验证

仅持久保存确认的市町村、沿岸、语言、公开数据快照与去重ID；不持久保存用户GPS、原始地址或语音。GPS坐标会用于GSI地址转换，避难地查询会发送至后端/GSI；服务器不记HTTP访问日志。导航会向地图服务传递目的地。通知 outbox 如启用则含接收人和通知数据，位于 `.cache/`，不会进入发布包。

75项自动测试通过（48 JavaScript + 27 Python），本轮通过原生画布验证左右卡片、日中双语指南、键盘和镜腿按钮、逐级返回及直达首页回退；历史网页数据及离线验证另列记录。详见 [VALIDATION.md](docs/VALIDATION.md)、[官方来源](docs/SOURCES.md)、[产品落地边界](docs/PRODUCT.md)。
